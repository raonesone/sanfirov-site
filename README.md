# sanfirov.art

Сайт-портфолио Александра Санфирова.

## Как вносить изменения

Откройте Claude с этой папкой и напишите обычным языком, например:

- «Добавь новый проект: „Северный свет“, короткий метр, 2026, вот ссылка на Kinescope, вот кадр для обложки»
- «Поставь „Северный свет“ первым»
- «Поменяй местами третий и пятый проекты»
- «Скрой проект „…“, но не удаляй»
- «Поправь текст в „Обо мне“»

Claude внесёт правку, покажет результат и отправит на сайт. Через минуту изменения будут на sanfirov.art.

## Что нужно для нового проекта

| Что | Пример |
|---|---|
| Название (рус / англ) | Северный свет / Northern Light |
| Тип (рус / англ) | Короткий метр / Short film |
| Год | 2026 |
| 1–2 предложения (рус / англ) | Идея, режиссёр, ваша роль |
| Ссылка на видео в Kinescope | https://kinescope.io/… |
| Кадр-обложка | лучший кадр, JPG/PNG, от 1920 px по ширине; сжимать не нужно |
| Титры (по желанию) | Режиссёр — …, Оператор — … |
| Дополнительные кадры (по желанию) | несколько стиллов для страницы проекта |

## Где что лежит

- `content/projects.json` — список работ; порядок в файле = порядок на сайте
- `content/site.json` — имя, тексты «Обо мне», соцсети, агентство
- `media/posters/` — обложки работ
- `media/stills/` — дополнительные кадры (папка на каждый проект)
- `media/photos/` — портреты и фото для «Контактов»
