# sanfirov.art — портфолио Александра Санфирова (кинематографист)

Статический сайт. `build.py` (Python 3.9+, только stdlib + Pillow) собирает `_site/` из:

- `content/projects.json` — список работ. **Порядок в файле = порядок в сетке на главной.**
- `content/site.json` — имя, роль, тексты «Обо мне», соцсети, агентство.
- `media/posters/<slug>.jpg|png|webp` — обложка работы (берётся автоматически по slug, или явно полем `poster`).
- `media/stills/<slug>/*` — необязательные кадры, показываются галереей на странице проекта (по имени файла).
- `media/photos/` — портреты, фото глаз для «Контактов», логотип-глаз.
- `static/` — копируется как есть (шрифты Sofia Sans / Sofia Sans Extra Condensed, свои, не Google Fonts).

Репозиторий: https://github.com/raonesone/sanfirov-site (GitHub CLI: `~/.local/bin/gh`, вход выполнен под raonesone).
Публикация: push в `main` → GitHub Actions (`.github/workflows/deploy.yml`) собирает сайт; выкладка на GitHub Pages идёт, только если в репозитории есть переменная `PUBLISH=true`.

## Поля проекта

```json
{
  "slug": "severnyi-svet",                       // адрес /work/severnyi-svet/, латиница-дефис, уникальный
  "title": {"ru": "…", "en": "…"},               // обязательно
  "type":  {"ru": "Короткий метр", "en": "Short film"},  // обязательно
  "year": 2026,
  "text":  {"ru": "1–2 предложения", "en": "…"},  // в сетке при наведении и на странице проекта
  "kinescope": "https://kinescope.io/abc123",    // ссылка или ID; пусто — без плеера
  "credits": {"ru": [["Режиссёр", "Имя"]], "en": [["Director", "Name"]]},
  "focus": "center 30%",                         // необязательно: какая часть кадра видна в превью 16:9
  "poster": "file.jpg",                          // необязательно, если файл назван по slug
  "hidden": true                                 // необязательно: скрыть, не удаляя
}
```

`placeholder: true` — пометка шаблонных проектов из первой версии; их нужно заменить реальными до запуска.

## Как работать

- Правки контента — только в `content/` и `media/`. HTML/CSS/JS живут в `build.py` (CSS и JS встроены в каждую страницу — так быстрее).
- После правки: `python3 build.py` — сборка печатает предупреждения (нет обложки, нет видео). Ошибки в JSON сообщаются по-русски с номером строки.
- Предпросмотр: `python3 build.py --serve` → http://localhost:8000. Если встроенный браузер получает 404 из папки на Рабочем столе (ограничение доступа macOS), скопировать `_site/` в scratchpad и раздавать оттуда.
- Без Pillow сборка тоже работает, но без сжатия картинок; в CI Pillow ставится сам.
- Затем коммит с понятным русским описанием и `git push` — сайт обновится примерно через минуту. Пользователь — не программист: объяснять по-русски и коротко, перед push показывать, что изменилось.

## Дизайн (не ломать)

Фон `#0B0B0B`, текст `#EDEDE6`, приглушённый `#8A8A85`. Заголовки — Sofia Sans Extra Condensed 900, верхний регистр; текст — Sofia Sans 200/300. Сетка 3 → 2 (≤1000px) → 1 (≤640px) колонки, превью 16:9 с обрезкой, зазор 8px. На десктопе подпись и описание появляются при наведении, на телефоне всегда под превью. Клик по превью открывает видео поверх сетки (лайтбокс, автозапуск, «Закрыть»/Esc/клик по фону/кнопка «назад»); адрес меняется на /work/<slug>/, так что ссылкой можно поделиться — по ней откроется страница проекта. Логотипа в шапке нет; глаз — только в подвале «Работ». Исходный макет — Design-артефакт https://claude.ai/artifact/YQmumkAHpYSeo3AWsWpDLe.

## Скорость

Обложки → WebP 480/800/1200/1600/1920 со `srcset`, первые три превью грузятся сразу, остальные лениво. Плеер Kinescope не грузится до нажатия Play (обложка-«фасад»). Шрифты свои, с preload нужного алфавита. Не добавлять фреймворки, внешние скрипты и счётчики без явной просьбы.
